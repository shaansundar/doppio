# Code of Conduct

doppio adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be welcoming and respectful, give and accept
constructive feedback gracefully, and focus on what is best for the community.
Harassment, insults, personal or political attacks, and publishing others'
private information are not tolerated.

## Scope

This applies in all project spaces: issues, pull requests, discussions and
any channel that represents the project.

## Reporting

Report unacceptable behavior privately to the maintainers. Use the
**Report content** option on GitHub, or open a
[private security advisory](https://github.com/shaansundar/doppio/security/advisories/new)
and title it "Code of Conduct". All reports are reviewed promptly and kept
confidential.

## Enforcement

Maintainers follow the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban or permanent ban, depending on severity.
